# Qué hacer si el código es incorrecto o vence

**En resumen:** cada código sirve una vez y por poco tiempo. Si la app no lo acepta, pide uno nuevo con **Reenviar Código** y escribe el último que te llegó.

## Qué revisar

1. Escribe el código **más reciente**. Si pediste varios, solo vale el último.
2. Revisa que no falte ningún dígito. Si el campo queda vacío, la app dice «El campo es requerido».
   ![El campo Código vacío con el mensaje de la app](/assets/es/acceso-y-cuenta/confirmar-el-codigo/codigo-vacio.png)
3. Si pasó mucho tiempo desde que lo pediste, toca **Reenviar Código** y usa el nuevo.
4. Si el número era otro, toca **← Atrás**, corrígelo y pide el código de nuevo.

## Lo que dice la pantalla

| Texto | Qué significa |
|---|---|
| «El campo es requerido» | No escribiste el código |
| «El campo es muy corto» | Faltan dígitos |

> [!NOTE]
> El mensaje exacto cuando el código es incorrecto o venció, cuántos intentos permite la app y si bloquea el acceso después de varios fallos todavía no está documentado: se comprueba con un celular real.

## Preguntas frecuentes

**¿Cuánto dura un código?**
Todavía no está documentado. Si dudas, pide uno nuevo.

**Me sigue diciendo que es incorrecto.**
Pide un código nuevo, espera a que llegue y escríbelo sin espacios. Si sigue fallando, escribe a soporte desde **Contáctanos**.
